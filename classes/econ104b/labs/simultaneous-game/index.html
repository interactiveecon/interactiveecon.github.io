ECON 104B — Game Theory

Solving a Simultaneous Game

Two players move at the same time. Identify each player's best responses, determine any dominant strategies, find all pure-strategy Nash equilibria, and compute the mixed-strategy Nash equilibrium.

Instructions

You will solve a 2×2 simultaneous-move game step by step. In the matrix, the first (orange) number in each cell is Player A's payoff; the second (blue) number is Player B's payoff.

You will be asked to answer the following:

  1. Best Responses. Click each payoff in the matrix that is a player's best response to one of the opponent's actions. Click the same payoff again to deselect.
  2. Dominant Strategies. Choose each player's dominant strategy from the dropdown — or None if no strategy dominates the other.
  3. Pure-Strategy Nash Equilibria. Add every PSNE (a strategy pair from which neither player wants to deviate). Leave the list empty if there is none.
  4. Mixed-Strategy Nash Equilibrium. Enter the probabilities p (Player A plays Top) and q (Player B plays Left) that make each player indifferent between their two actions.

For each step, enter your answer and click Check Answer. If your answer is incorrect, hints and the worked solution are available.
