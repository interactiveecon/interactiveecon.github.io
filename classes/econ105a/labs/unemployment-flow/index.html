ECON 105A — Unemployment

Steady-State Flow Simulator

Watch how the labor market converges to its steady-state unemployment rate by simulating the monthly flows of workers between employment and unemployment.

Instructions

The matching model assumes that the labor market is in steady state: in every month, the number of workers losing jobs equals the number of workers finding jobs, so the unemployment rate stays constant. This lab lets you watch that steady state emerge from the underlying flows.

Set the parameters:

  1. Job-separation rate (s). Fraction of employed workers losing their jobs each month.
  2. Job-finding rate (f). Fraction of unemployed workers finding a job each month.
  3. Labor force (H). Total workers (employed + unemployed).
  4. Initial unemployment (U₀). Where the simulation starts.

Then use the simulation controls:

  • Step advances the simulation by one month.
  • Run advances one month every 150ms until you click Pause or it reaches steady state.
  • Run to steady state jumps straight to convergence.
  • Reset returns to month 0 with the current parameters.

Try setting U₀ to very different starting points (0 workers unemployed, or all 100 workers unemployed) and watch what happens. The unemployment rate always converges to the same value: u* = s/(s+f).
