ECON 105A — Inflation

Ex Ante vs. Ex Post Real Interest Rates

Step into the shoes of a lender, then a borrower, and see how unexpected inflation drives a wedge between the real return both sides expected and the one they actually got.

Instructions

This three-phase tutorial walks you through the distinction between the ex ante real rate (planned, based on expected inflation) and the ex post real rate (realized, after actual inflation is observed).

You will work through:

  1. Single Loan. As a lender, set the nominal rate that delivers your desired real return, then compute the realized real return after actual inflation is revealed.
  2. Both Sides. Flip perspectives to the borrower on the same loan and see how the gain or loss is mirrored.
  3. Many Loans. Run 1,000 random inflation realizations and watch how the distribution of realized real returns centers on — but spreads around — the expected real return.

Each phase unlocks once the previous one is complete. Use New Scenario to redraw values within a phase, or Start Over to reset everything.
